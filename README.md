# Shaft Reaction Monitor

갤럭시 탭 S10 라이트의 가로 화면(2112×1320 물리 픽셀, 약 1056×660 CSS 픽셀)을 기준으로 구성한 메인 엔진 샤프트 반력 Jack-up 계측 시스템 와이어프레임입니다. 세로 화면에서도 레이아웃이 재배치됩니다.

## 주요 화면

- 작업 홈 및 누적 시험 이력
- 장치 설정: 선종·베어링 구성, 장치 연결·게이지 지정
- 베어링별 게이지 선택 후 한 번에 연결·매핑 적용
- 베어링 선택: 유압잭·목표 반력·허용범위 입력
- 통합 측정·분석: Lifting/Lowering 수신 곡선과 작업자 보정
- 압력 구간별 변위 자동 기록 및 측정 데이터 초기화
- 원시값·최종값·수정 이력
- 회차 제한 없는 측정 기록과 베어링별 전체 회차 Excel 저장(첫 시트에 수신값 전건 기록)
- 선택 베어링 측정 시작과 재측정 시작마다 회차가 1차, 2차, 3차로 자동 증가하며 각 저장 기록은 시작 당시 회차를 유지합니다. 새 시험 시작에서 회차를 1차로 초기화합니다.
- 작업 홈·장치 설정의 요약 정보에는 회차를 표시하지 않습니다. 작업 홈의 최근 베어링 측정 기록은 데이터 이력에 저장된 회차별·베어링별 기록을 최신순으로 보여주고, Test ID를 누르면 해당 저장 시점의 데이터 이력을 엽니다. 데이터 이력을 초기화하면 작업 홈 목록도 비워지며 결과 리포트 스냅샷은 유지됩니다. 데이터 이력 상단의 회차 수는 저장 버튼 횟수가 아니라 실제 데이터 측정 시작 횟수로 계산하며, 개별 저장 기록에는 시작 당시 회차를 유지합니다.
- 현재 시험의 모든 저장 시점·회차 Excel/CSV 내보내기 및 베어링별 PDF 미리보기
- 결과 리포트 종합 판정 탭에서 저장된 회차마다 기록 수·분석 완료 수·회차 판정을 누적 표시합니다. 베어링별 반력 요약도 1차·2차를 별도 행으로 유지하며, 같은 회차·베어링에서 여러 번 저장한 경우 요약에는 마지막 저장값을 표시합니다.
- `데이터 저장` 시 해당 시점까지의 수신값과 현재 분석 상태를 독립 스냅샷으로 누적합니다. 측정 종료 후 분석선이 계산되면 자동 분석 결과도 함께 저장하며, 기울기를 수동 조절한 경우에만 보정 작업자·사유를 필수로 확인합니다. 기록 표시 종료점은 선택 사항입니다. 현재 시험의 데이터 이력을 초기화해도 결과 리포트의 저장 스냅샷은 남고, `새 시험 시작` 확인 시 두 이력이 모두 초기화됩니다.
- 같은 베어링을 다시 측정하면 이전 수신 기록은 별도 이력으로 남기고 새 수신 기록을 시작합니다. 기록 표시 종료점을 설정한 뒤 저장하면 해당 종료점이 저장 시점의 그래프·PDF에 적용됩니다. 데이터 이력의 수신값 표는 저장된 그래프 표시 구간을 기본으로 보여주고 `전체 원시값`으로 전환할 수 있습니다. Excel 원시 수신값 시트에는 표시 구간과 무관하게 전체 수신값을 보존합니다. 베어링을 바꾸어도 이전 베어링의 저장 이력은 삭제하지 않습니다.
- SAG 계산·그래프와 우측 상단 경고 팝업

## 시연 범위

- 실제 Bluetooth 연결이 아닌 예시 데이터로 동작하는 UI 프로토타입입니다.
- 측정·이력은 시연 세션의 메모리에 보관되며 새로고침하면 초기화됩니다. 실제 앱 저장소 및 BLE 연동은 별도 개발 대상입니다.
- Excel(`.xlsx`)과 CSV 4종 묶음(`.zip`)은 시연 세션에 남아 있는 원시 수신값·분석 결과로 브라우저에서 다운로드합니다. PDF는 전체 회차 미리보기 후 인쇄 대화상자에서 PDF로 저장하며, Android 앱의 영구 저장·공유 기능은 별도 구현 대상입니다.
- 압력계 1대 공유 구성은 임시안이며, 최종 센서·모듈 수량과 연결 구조는 HW 협의 후 확정합니다.
- 베어링별 순차 측정을 전제로 하며, 측정 중에는 장치·베어링 변경을 제한합니다.
- 측정이 시작된 뒤 다른 메뉴를 열어도 예시 수신 기록은 계속 쌓입니다. 실제 Android 앱에서는 BLE 수신을 화면 표시와 분리하고 백그라운드 운용 조건을 별도로 검증해야 합니다.
- 설정완료로 최초 연결한 장치·게이지 매핑을 기억하고, 같은 구성의 장치가 감지되면 자동 재연결하는 흐름을 시연합니다. 자동 재연결은 측정을 자동 시작하지 않습니다.
- 매핑 기억에는 브라우저 로컬 저장소를 사용하며, 저장소가 제한된 미리보기에서는 새로고침 후 복원이 제한될 수 있습니다. 실제 Android BLE 검색·재연결 및 영구 저장은 별도 구현 대상입니다.

GitHub Pages는 저장소 루트의 `index.html`을 배포합니다. 이 파일은 화면을 직접 렌더링하는 독립 HTML입니다. 태블릿 높이를 뷰포트에 맞추는 CSS를 사용하므로, 높이를 자동 계산하는 `iframe` 래퍼로 다시 감싸지 마세요.
