# Shaft Reaction Monitor

1007×601 태블릿 가로 화면을 기준으로 구성한 메인 엔진 샤프트 반력 Jack-up 계측 시스템 와이어프레임입니다.

## 주요 화면

- 작업 홈 및 누적 시험 이력
- 장치 설정: 선종·베어링 구성, 장치 연결·게이지 지정
- 베어링별 게이지 선택 후 한 번에 연결·매핑 적용
- 베어링 선택: 유압잭·목표 반력·허용범위 입력
- 통합 측정·분석: Lifting/Lowering 수신 곡선과 작업자 보정
- 압력 구간별 변위 자동 기록 및 측정 데이터 초기화
- 원시값·최종값·수정 이력
- 결과 요약 및 리포트
- SAG 계산·그래프와 알람·경고

## 시연 범위

- 실제 Bluetooth 연결이 아닌 예시 데이터로 동작하는 UI 프로토타입입니다.
- 측정·이력은 시연 세션의 메모리에 보관되며 새로고침하면 초기화됩니다. 실제 앱 저장소 및 BLE 연동은 별도 개발 대상입니다.
- 압력계 1대 공유 구성은 임시안이며, 최종 센서·모듈 수량과 연결 구조는 HW 협의 후 확정합니다.
- 베어링별 순차 측정을 전제로 하며, 측정 중에는 장치·베어링 변경을 제한합니다.

GitHub Pages는 저장소 루트의 `index.html`을 배포합니다.
